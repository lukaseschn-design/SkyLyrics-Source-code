# Changelog

All notable changes to SkyLyrics are documented in this file.

## [1.0+1.21.11] - 2026-11-08

### Highlights
- Initial public release for Minecraft 1.21.11 (Fabric).
- Real-time synchronized lyrics integration via Windows SMTC (Spotify, YouTube, and media players).

### Lyrics Rendering
- **3D Air Lyrics:** Lyrics hover in 3D around the player with smooth animations, drift, and beat pulsing.
- **Sky Lyrics:** Full lyric lines mapped across the celestial dome.
- **HUD Mini Player:** Sleek top-bar pill showing playback status, artist, song progress, and live lyrics.

### User Interface & Audio
- Redesigned title screen with native Minecraft button widgets and custom Aurora animated backdrop.
- Interactive keycap keyboard editor in the controls screen.
- Integrated human-made pixel art logo and clean Minecraft font branding across all screens.
- Custom UI audio system with subtle click and hover sounds.

### Customization & Performance
- Over 20 built-in color presets and custom RGB palettes.
- Bundled with 20+ open-source typefaces (Inter, Poppins, Bebas Neue, Quicksand, Fredoka, etc.) plus custom TTF loading.
- Fully client-side rendering pipeline optimized for Sodium and Iris Shaders.
