# Changelog

## 1.0 (1.21.11)
- Initial release for Minecraft 1.21.11 (Fabric)
- Synchronized song lyrics in 3D air mode and on the sky dome
- Mini player HUD widget
- Automatic song detection via Windows SMTC (Spotify, browser, local players)
- Settings menu with color themes and font choices
- Custom title screen and loading screen
- In-game keybind editor
